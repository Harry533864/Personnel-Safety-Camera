# Baumer 工业相机版配置参数与性能说明

适用版本：AI 人员安全相机平台 Baumer 工业相机版  
测试口径：边缘端本地采集、本地 AI 推理、前端 MJPEG 实时预览叠加检测框和 ROI 区域  
数据来源：Baumer 分支样机运行状态实测记录

## 1. 核心配置概览

| 项目 | 参数 |
| --- | --- |
| 相机类型 | Baumer 工业相机 |
| 采集后端 | `baumer_neoapi` |
| 当前采集分辨率 | 2448 x 2048 |
| 有效像素级别 | 约 500 万像素 |
| 图像格式 | BGR8 |
| 前端预览方式 | MJPEG over HTTP |
| AI 推理模型 | ASV_person_FP16 |
| 推理框架 | TensorRT FP16 |
| 模型输入尺寸 | 640 x 640 |
| 检测目标 | 人员检测 |
| 检测阈值 | 0.5 |
| ROI 判断方式 | 区域重叠判断 overlap |
| ROI 重叠阈值 | 0.1 |
| 检测区域 | 支持多 ROI 区域，区域坐标按画面比例归一化保存 |
| 报警显示 | 人员进入 ROI 后显示 WARNING 标识，并保留检测框与区域框 |

## 2. 当前实测性能

| 场景 | 分辨率 | AI 状态 | 采集帧率 | AI 推理帧率 | 前端预览帧率 | 单帧推理耗时 |
| --- | --- | --- | ---: | ---: | ---: | ---: |
| 高分辨率人员检测预览 | 2448 x 2048 | 开启 | 约 22-23 fps | 约 21-22 fps | 约 21-22 fps | 约 40-50 ms |

说明：

- 上表为 Baumer 工业相机版在最大 2448 x 2048 分辨率下的实际运行表现。
- 前端预览帧率包含检测框、ROI 框、WARNING 标识等叠加效果。
- 该帧率不是单独 TensorRT 模型 benchmark，而是包含相机采集、图像搬运、AI 推理、结果绘制和 MJPEG 预览的端到端效果。
- 实际帧率会受现场光照、曝光时间、目标数量、网络质量、浏览器性能和散热状态影响。

## 3. 可配置能力

| 类别 | 支持能力 |
| --- | --- |
| 分辨率 | 支持按现场画质和实时性需求配置，当前 Baumer 样机已验证 2448 x 2048 |
| 曝光 | 支持自动曝光和手动曝光配置 |
| 增益 | 支持自动增益和手动增益配置 |
| 白平衡 | 支持连续白平衡 |
| 检测开关 | 支持前端开启/关闭 AI 检测 |
| 检测阈值 | 支持前端配置置信度阈值 |
| 检测区域 | 支持在实时画面上绘制 ROI，保存后自动适配显示比例 |
| 模型管理 | 支持模型列表读取和模型切换 |
| 异常提示 | 支持检测框、ROI 框和 WARNING 状态提示 |
| 运维状态 | 支持查看相机在线、模型加载、推理帧率、最近错误等状态 |

## 4. 部署与网络参数

| 项目 | 参数 |
| --- | --- |
| 后端 API 端口 | 5000 |
| 前端默认后端地址 | `http://192.168.1.173:5000` |
| 前端本地服务端口 | 127.0.0.1:51730 |
| 相机当前网络别名 | `10.10.10.2`、`192.168.18.173`、`192.168.1.173` |
| 前端发布目标机 | `192.168.1.172` |
| 预览方式 | 浏览器访问本地前端，由前端连接相机后端 MJPEG 预览接口 |

## 5. 长期运行稳定性配置

| 项目 | 配置 |
| --- | --- |
| 服务自启动 | 后端服务和媒体服务支持 systemd 自启动 |
| 日志策略 | 关闭高频访问日志，避免状态轮询持续写盘 |
| 日志轮转 | 后端日志按小体积轮转，避免长期运行占满 `/home` |
| 存储守护 | 定时清理运行临时文件、旧日志、旧部署包、缓存和过期录像 |
| 低空间保护 | 空间不足时自动清理缓存，避免模型加载和配置写入受影响 |
| ROI 适配 | ROI 使用归一化坐标保存，分辨率变化后不易发生区域变形或偏移 |

## 6. 客户沟通建议口径

当前 Baumer 工业相机版在 2448 x 2048 高分辨率下，可实现约 21-22 fps 的端到端 AI 人员检测预览。该性能包含相机采集、AI 推理、检测框/ROI/WARNING 叠加和浏览器实时预览，更接近现场实际使用体验，而不是单独模型算力跑分。

如客户需要更低延迟或更高帧率，可根据现场验收要求进一步降低输出分辨率，例如 1920 x 1080 或 1280 x 720，并进行现场复测确认。
